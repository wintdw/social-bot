Treatment: hand-crafted isometric illustration, drawn with the `anatomy` skill
(<https://github.com/wheresryan22/anatomy>).

For the post whose *idea* needs a picture — a mechanism, a structure, an
inventory of parts, a before/after. The subject is drawn as a small isometric
scene of real physical parts (a rig, a gauge, a cabinet, a plotter), each placed
deliberately, four-tone shaded and stacked in correct painter's order, with
short labels in plain capitals and one quiet title line. The skill's live SVG
preview is interactive; the host's Chromium screenshots it to the PNG a post
uploads, and the file lands in the same served `/images/` store as the
HTML5 plate, so the draft points at it the same way.

**Use it selectively.** The default image is still the source article's own
cover, and the HTML plate still owns straight wiring (what calls what);
reach for an illustration only when the drawn object carries the message better
than either. Never for every post, never as a standing rotation, and never a
photographic or model-generated image — a person draws it, and the human review
gate is unchanged.
